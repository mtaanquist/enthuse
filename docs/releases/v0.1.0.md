First release of Enthuse, a media player for Windows and Linux. It browses folders on local disks and network shares, plays them with libmpv, remembers where you stopped, and moves on to the next file in the folder.

This is an early release (0.x): expect rough edges, and settings or stored data may change between versions.

## Downloads
- **Windows (x86_64):** unzip `enthuse-0.1.0-windows-x86_64.zip` anywhere and run `enthuse.exe`. libmpv is included.
- **Linux (x86_64):** unpack `enthuse-0.1.0-linux-x86_64.tar.gz` and run `./enthuse`. Needs libmpv from your distribution (see `README.txt` in the archive).

## What's in it
- **Sources and browsing.** Add local folders, Linux mounts and Windows UNC shares. Browse them in a list or grid with natural sorting, video thumbnails, and watched and time-left badges. Offline shares show as Offline. (#3, #4, #38, #63, #68)
- **Home and Recent.** Continue watching, your sources, and a list of recently played files. (#64, #70)
- **Playback.** libmpv drawn under the app's own controls: seek bar, volume, audio and subtitle tracks, auto-hiding controls and keyboard shortcuts. A clear message when a file can't be played. (#5, #6, #17, #20, #65, #70)
- **Resume and watch state.** Picks up where you stopped, also for files outside your sources. A file counts as watched by percentage, by time left, or whichever comes first, so long episodes with long credits are handled. Resume can be turned off globally or per folder. (#8, #18, #39, #41, #50, #69)
- **Up next.** Continues to the next file in the folder after a countdown you can skip or cancel, or turn off in Settings. (#7, #35, #66)
- **Picture-in-picture.** The video becomes a borderless, always-on-top mini player that keeps its aspect ratio and can be resized from any edge, while the browser opens in its own window with a now-playing bar. (#9, #19, #47, #48, #49, #67)
- **Settings.** Watched rule, resume, auto-next, thumbnails on network shares, and per-folder overrides. (#69)
- **Keyboard and touch.** Arrow keys, Enter and Escape work through every screen; targets are sized for touch. (#70)

## Known limitations
- A network share that drops during playback is not handled gracefully yet (#57).
- On Wayland the PiP window can't be kept on top or placed by the app (see the README for a KDE window rule).
- Packaged installers are not available yet; this release is a zip and a tarball (#15).
